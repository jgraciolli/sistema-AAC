# sistema-AAC
Um sistema AAC é aquele que permite com que pessoas com dificuldade para se comunicar possam expressar aquilo que querem dizer de uma forma alternativa .
Pode encobrir diferentes tipos de deficiência.
É um sistema que segue um conjunto de instruções as traduzindo para alguma linguagem
Sistemas AAC podem ser utilizados para diferentes tipos de comunicação, seja com pessoas ou com computadores
Um vídeo de exemplo que demonstra a evolução de sistemas AAC ao longo dos anos: https://www.youtube.com/watch?v=eVQJaeHEfJA

# Análise do app Papuguinho

## O que faz o app do papuguinho?

Um aplicativo de AAC com comandos extremamente simples,

## O que o app possui?

- divido por categoria, 
- instruções muito claras
- seleção através do teclado de instruções 
- exibição de instruções em ordem
- botão de apagar ultima instrução
- botão de apagar tudo
