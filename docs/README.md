# sistema-AAC
- Um sistema AAC é aquele que permite com que pessoas com dificuldade para se comunicar possam expressar aquilo que querem dizer de uma forma alternativa .
- Pode encobrir diferentes tipos de deficiência.
- É um sistema que segue um conjunto de instruções as traduzindo para alguma linguagem
- Sistemas AAC podem ser utilizados para diferentes tipos de comunicação, seja com pessoas ou com computadores
- Um vídeo de exemplo que demonstra a evolução de sistemas AAC ao longo dos anos: https://www.youtube.com/watch?v=eVQJaeHEfJA

# Manual do usuário

## Instalação

- Primeiramente instale o aplicativo e [adicionar etapas de instalação]

## Utilização

- Para começar você deve criar uma prancha com nome [Botão criar prancha]
- Criar um card com a palavra e uma categoria e associá-lo a uma prancha [Botão criar card de palavra]
- (Opcional) Reordenar a posição do card na prancha [Botão de arrastar]
- Depois gerar uma imagem [Botão gerar imagem (IA)]
- (Opcional) Você pode editar card de palavra [Botão editar card de palavra]
- (Opcional) Você pode excluir card de palavra [Botão excluir card de palavra]
- (Opcional) Você pode reproduzir a palavra
- Então gerar a frase [Botão gerar frase]
- Finalmente você pode reproduzir a frase [Botão reproduzir frase de palavra]

Link do app: https://estudio.papuguinho.com/
