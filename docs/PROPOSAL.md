# Proposta para desenvolvimento de um sistema CAA (Sistemas de comunicação aumentativa e alternativas) do tipo comunicação com auxílio utilizando método de telas interativas dinâmicas

- Eu necessito de um sistema de Acessibilidade para pessoa com problema de comunicação no qual a pessoa pode interagir de modo indireto com outras pessoas por meio de seleção de palavras para texto falado.

## O sistema deve ter todos os requisitos abaixo:

-	A acessibilidade necessita ser fortemente pensada para o usuário final
-	O sistema deve possuir várias palavras para serem selecionada
-	As palavras devem ter no máximo um verbo, um pronome ou um substantivo
-	Cada palavra deve possuir uma imagem com tamanho personalizável clicável
-	Conforme essas palavras são selecionadas elas formam frases
-	Antes do usuário entrar, o sistema deve avaliar como deve se adaptar ao usuário
-	O sistema deve ter um mecanismo de busca para as imagens
-	Completar as frases de acordo com categorias de perguntas simples e sequenciais (exemplo: quem, o quê, por quê, como)
-	As telas devem ser dinâmicas, ou seja, o usuário deve pode adicionar novas ações ou editar ações já existentes
-	Quando o sistema construir uma frase ele necessita falar essa frase em voz alta
