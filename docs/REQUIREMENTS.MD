# Objetivo

- Criar um sistema de AAC de tipo comunicação com auxílio utilizando método de telas interativas dinâmicas

# Principal problema

- Pessoas com dificuldade na fala não conseguem se comunicar adequadamente

# Domínio

## Entidades de domínio

E1 - Card de palavra
E2 - Prancha

# Requisitos

## Requisitos funcionais

RF1 - Criar prancha
RF2 - Visualizar prancha
RF3 - atualizar prancha
RF4 - Excluir prancha
RF5 - Visualizar pranchas
RF6 - Criar card e atribuir a uma prancha
RF7 - Visualizar prancha
RF8 - atualizar card
RF9 - Excluir card
RF10 - Visualizar cards de uma prancha
RF11 - Reproduzir palavra
RF12 - Reordenar cards da prancha
RF13 - Gerar imagem com base na palavra (IA)
RF14 - Atribuir imagem ao card
RF15 - Construir frase com palavras
RF16 - Reproduzir frase

## Requisitos não funcionais

RNF1 - Completar palavras com base em perguntas simples (como, por quê, o quê, quem)
RNF2 - Buscas palavras da prancha
RNF3 - Visualizar histórico de alteração das pranchas
RNF4 - Visualizar histórico de alteração dos cards
