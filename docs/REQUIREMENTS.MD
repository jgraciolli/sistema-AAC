# Objetivo

- Criar um sistema de AAC de tipo comunicação com auxílio utilizando método de telas interativas dinâmicas

# Principal problema

- Pessoas com dificuldade na fala não conseguem se comunicar adequadamente

# Domínio

## Entidades de domínio

E1 - Card de palavra
E2 - Prancha

# Requisitos

## Requisitos funcionais

RF1 - Criar prancha
RF2 - Visualizar prancha
RF2 - Editar prancha
RF3 - Excluir prancha
RF4 - Criar card e atribuir a uma prancha
RF5 - Visualizar prancha
RF5 - Editar card
RF6 - Excluir card
RF7 - Reproduzir palavra
RF7 - Reordenar cards da prancha
RF8 - Gerar imagem com base na palavra (IA)
RF9 - Atribuir imagem ao card
RF10 - Construir frase com palavras
RF11 - Reproduzir frase

## Requisitos não funcionais

RNF1 - Completar palavras com base em perguntas simples (como, por quê, o quê, quem)
RNF2 - Buscas palavras da prancha
